# 大临床数据分析方法：框架与文献参考

这份参考回答一件事：**在公开的高粒度重症临床数据上，现在用哪些分析方法、各自回答什么问题、文献把哪一层钉住了、哪一层已经饱和、哪一层还没有前瞻证据。**

它不是算法目录，也不是又一篇「MIMIC 死亡预测综述」。读法是：

1. 先用 [总框架](./00-framework.md) 判断你的问题属于哪一类问法、做成标准是什么、该不该开题。
2. 再用 [六个方法家族](./01-six-families.md) 按文献把机理拆开。家族之间不可比 AUROC。
3. 最后用 [横切问题与落地](./02-cross-cutting.md) 检查观察过程、跨库、公平、实施——这三层会改写前面所有成绩的解释。

主文本依据飞书多维表「公开成人重症数据库·研究分析」：

- 编年史第七卷《算得更准：人工智能与实施》  
  https://gcn3zg3jvfzs.feishu.cn/docx/QFtXdRjd4oQMBOxZVXTc65X4nwe
- 成人研究问题 343 条（A1–A16）
- 领域分类（做成标准 G1–G8、饱和度）
- 核心文献 121 条
