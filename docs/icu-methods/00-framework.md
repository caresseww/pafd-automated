# 总框架：先问问题，再选方法

## 0. 一句话立场

大临床数据上的分析方法，必须按**问法**分类，不能按**模型名字**分类。

「梯度提升树 / LSTM / Transformer / 因果森林」不是方法学单位。同一套 LightGBM，既可以做饱和的院内死亡预测（A1），也可以做尚未前瞻验证的异质性处理效应（A6）。把它们放进同一张性能表，没有方法学依据。

本参考的单位是：**这个问题在问什么 → 数据条件是否允许问 → 用哪个方法家族估计 → 横切层会怎样改写解释 → 做成标准是否达到。**

---

## 1. 四层框架

```
问法（A1–A16）          先看饱和度。伪问题直接停。
    ↓
数据条件                 四类输入 × 公开库 × 密度等级（3/2/1/0/X）
    ↓
方法家族（一至六）        按目标选家族，不按时髦选架构
    ↓
横切层                   观察过程 · 跨库 · 公平 · 基准 · 评价
    ↓
做成标准（G1–G8）        内部 AUROC 从来不算完成
```

第五卷已经把产量写清楚：至 2022 年 8 月，公开库临床原著 1,307 篇，死亡终点 67.2%，单库 91.5%，以 AUROC 为主要指标 73.4%，中位值 0.840。本参考不重复产量史。本参考写的是产量史没有展开的中间层——分析人员到底在挖什么、挖到的是什么、哪一步算做成。

两条与常识相反的结论，必须先放在框架门口，否则后面所有「成绩」都会被读错：

1. **模型主要在学「医生给谁做了什么检查」，不是在学生理。** 只看测没测、不看数值，即可达到完整模型区分度的 84%–93%；三个任务里有两个超过 SOFA / OASIS。
2. **落地发生在信号与影像，不在预测。** 预测是文献最拥挤的地方。进入临床整合的研究里，死亡预测占零，影像与视频占一半以上。

第一条解释第二条。观察过程是各家医院的习惯；学到习惯就换不了医院；换不了医院就进不了工作流。

第三条是把六个家族并列之后才看得出来的：过去五年重心已从「预测谁会死」移向「病程会怎么走」与「治疗对谁有用」，但这两个新方向至今一项前瞻验证都没有。

## 2. 第一层：问法分类（A1–A16）

飞书「成人研究问题」把公开库上真正被问过、正在被问、不该再问的问题分成十六族。**先看饱和度，再开题。** 饱和度不是口味，是文献计量之后的工作纪律。

| 问法 | 问的是 | 饱和度 | 典型伪动作 | 做成时必须多报的东西 |
|---|---|---|---|---|
| A1 预后 | 这个人后来怎样 | 饱和 / 拥挤 | 换模型涨 AUROC 0.02 | 外验证、校准、时间零点、竞争风险 |
| A2 发生 | 某事件会不会在窗口内出现 | 拥挤 | 把定义战写成新模型 | 事件可操作定义、警报策略、每小时假警报 |
| A3 轨迹 | 病程有几种走法 | 活跃 | 只报簇间病死率差 | 外验证、竞争风险、平均后验概率、治疗决策是否伪装 |
| A4 表型 | 同一诊断下有几类人 | 活跃 | 换特征即换簇还当新发现 | 簇必须修饰治疗，且不能被 SOFA 四分位解释掉 |
| A5 关联 | 某化验 / 某比值与死亡 | 伪问题 | 化验比值 × 综合征 × 死亡工厂 | 不要做 |
| A6 因果 | 若按某策略治疗，结局是否不同 | 活跃 | 把治疗当特征翻转预测 | 靶试验五要素 + 异质性的整体检验 |
| A7 决策 | 这一步该给多少 | 活跃 | 离策略估计当「优于医师」 | 双重 OPE、有效样本量、与实践的总变差上限 |
| A8 评分 | 尺子本身 | 饱和 | 再做一个死亡评分 | 校准重于 AUROC；决策曲线仍少报 |
| A9 多模态 | 笔记 / 片 / 心电 / 波形能否加信息 | 新兴 | 只报全模态 vs 单模态一个对比 | 穷举边际贡献；缺失模态；融合层次 |
| A10 基础模型 | 预训练是否省标注、能否零样本 | 新兴 | 把「更大」写成进展 | 样本效率、未见医院、未见任务、时间稳定性 |
| A11 运营 | 路由、拥堵、转出 | 薄 | 用死亡模型冒充路由 | 决策点与可执行动作 |
| A12 质量 | 协议依从、标准化死亡比 | 空 / 主场在登记网 | 把 HAI 既当质量指标又当预测标签 | 登记传统的做成标准是 SMR，不是 MIMIC 时序 |
| A13 公平 | 谁被模型伤害 | 活跃 | 只报总体 AUROC | 观察过程、标签偏倚、种族校准、学术中心→社区医院 |
| A14 基准 | 任务协议本身 | 活跃 | 继续抄 Harutyunyan 第一项 | 锁划分、锁队列、多库同一任务 |
| A15 隐私 | 去标识、合成、权重分享 | 薄 | 忽略 DUA | 再识别、合成数据放大少数群误差 |
| A16 实施 | 上线后病人是否更好 | 新兴 | 静默部署当完成 | 持续采纳率、结局、SPIRIT-AI / CONSORT-AI / DECIDE-AI |

题库里明确标成**伪问题、不要做**的三条：

- F-00-01 化验比值 × 综合征 × 死亡工厂（A5）
- F-00-02 换模型涨 AUROC（A1）
- F-00-03 无时间零点、无干预定义的预测文（A1）

题库里明确标成**饱和工厂**的四条：院内死亡 24/48h（F-01-01）、脓毒症死亡（F-02-04）、KDIGO 发生（F-05-01）、强化 vs 宽松血糖（F-15-15）。换模型涨 0.02 不是新问题。

343 条问题的饱和度分布（2026-09 快照）：拥挤 112、活跃 76、空 59、薄 46、新兴 43、饱和 4、伪问题 3。拥挤不是「还可以再发一篇」，是「必须改问法或改做成标准才能开题」。

### 2.1 问法与六个方法家族的对照

| 问法 | 主要落入的方法家族 | 不要误落入 |
|---|---|---|
| A1 预后、A2 发生、A8 评分 | 家族一 监督预测 | 不要把死亡 AUROC 写成「决策」 |
| A3 轨迹 | 家族三 轨迹聚类 | 不要和横断面表型比 κ 当同一件事 |
| A4 表型 | 家族二 横断面聚类 | 簇能分开 ≠ 能迁移 ≠ 能改治疗 |
| A6 因果 | 家族六 因果机器学习 | 不要翻转预测模型的治疗特征 |
| A7 决策 | 序贯决策（家族一的出口，不是家族一本身） | 不要用加权重要度抽样的高回报当优于医师 |
| A9 多模态、A10 基础模型 | 家族四 表征学习；横向「加维度」 | 标度律 28M 后饱和，要的是数据不是更大模型 |
| A13 公平、A14 基准 | 横切层 | 不是又一个下游任务 |
| A16 实施 | 第四、五部分（落地） | 上线 ≠ 有效 |

图方法（家族五）在题库里没有单独的 A 码，因为它几乎从不单独构成临床问题——它是表征的一种构造方式。读图论文时，先问它回答的是 A1、A4 还是 A10。

## 3. 第二层：数据条件

方法能不能成立，先看数据，不看模型。

### 3.1 四类输入

这张表是全卷的索引。凡是需要医师主动采纳的，落地都困难；凡是能嵌进设备或既有工作流的，落地都相对顺利。

| 输入 | 公开资源 | 典型任务 | 落地路径 | 是否依赖医师采纳 |
|---|---|---|---|---|
| 结构化时序 | 丰富，小时至日级 | 死亡、脓毒症、AKI 预测 | 预警系统 | 是 |
| 连续波形 | 少，分钟至毫秒级 | 循环衰竭、低血压预报；闭环 | 监护仪、呼吸机内置 | 闭环时否 |
| 影像与视频 | MIMIC-CXR；院内 PACS 丰富 | 检出、分诊、定量 | 影像工作流内置 | 部分 |
| 文本 | MIMIC-IV-Note；院内记录 | 摘要、鉴别、文书 | 电子病历插件 | 是 |

「高维」有三重含义，难度递增：变量多（一百到数百）、时间点密（分钟到小时，每人数百到数千观测）、模态多（表格、时序、文本、影像、波形）。

量级必须先摆出来，后面所有讨论都取决于这几个数：

| 资源与口径 | 维度 |
|---|---|
| YAIB 支持的五个库合计 | 334,812 次 ICU 停留 |
| MIMIC-IV 入室首 24 小时 | 84,013 次入院 × 113 个临床特征 |
| MIMIC-IV 全库事件流化（ETHOS/ARES） | 285,622 条时间线，>3.57 亿 token |
| ICareFM 预训练语料 | 650,000 次住院、>10 亿次测量（预印本，一键包未上 PhysioNet） |
| HiRID | 710 个原始变量 → 209 个一致测量，5 分钟 |
| HAIM 多模态子集 | 34,537 样本 / 7,279 住院 / 4 模态 / 11 源 |
| MIMIC-CXR | 377,110 张胸片、227,835 次检查 |

### 3.2 密度等级（能不能当主分析）

领域分类把每个库在每个域上的资格写成五档。这是开题的第二道门。

| 档 | 含义 | 纪律 |
|---|---|---|
| 3 密 | 该域是库的主场 | 可以当主数据 |
| 2 有 | 字段在，定义或密度够二次分析 | 可进模型，须写清缺失 |
| 1 薄 | 代理或残缺字段 | 只可描述或敏感度 |
| 0 无 | 结构上没有或去标识删掉 | 不要问这个问题 |
| X 不允许 | 问这个问题会改写库的设计目的 | 换库 |

例：公开层几乎没有护理过程真值、患者报告结局、SDOH 金标准、非英语叙事、真正随机化的治疗意图。这些问题标成「空」，不是「还没人做」，是「这张桌子上问不了」。

### 3.3 三个人群的数据条件不对称

| 人群 | 结构化时序 | 波形 | 影像 | 前瞻实施证据 |
|---|---|---|---|---|
| 成人 | 七个公开库；ICareFM 65 万住院 | HiRID、OneICU、VitalDB | MIMIC-CXR 37.7 万 | TREWS、闭环通气、多项大模型试验 |
| 儿童 | 仅 PIC，无第二家可外验证 | 无公开资源 | 无对等资源 | 几乎无 |
| 新生儿 | 无（MIMIC-III NICU 切片无胎龄，MIMIC-IV 已移除） | PreMo：心率血氧，6,837 例 | 无 | HeRO 随机对照（2011） |

儿科的完成标准在指南里走得比数据快：2020 年儿科指南已拒绝直接移植成人 Sepsis-3，2024 年 Phoenix 用超过 360 万次就诊推导，但公开层没有第二张桌可以执行新标准。在 PIC 上再报一个死亡 AUROC，是站在 2016 年的位置上。

## 4. 做成标准：G1–G8

「尺子世代」写的是后一代不废除前一代，但每一代的**做成**不同。用错做成标准，就会把登记网的问题拿到 MIMIC 上做，或把内部区分度当成进展。

| 世代 | 核心问题 | 做成标准 |
|---|---|---|
| G1 对标 | 这间 ICU 比预期死得多吗 | 多中心校准过、能发布 SMR 的评分 |
| G2 过程 | 衰竭是过程还是标签 | 能逐日描写并进入共识（SOFA） |
| G3 定义试验 | 早期目标导向是否救命 | 改变复苏实践的试验；定义一变历史队列不能相加 |
| G4 可复现 | 同一套 SQL 上吵架 | 陌生人能按 DUA 复现抽取 |
| G5 基准 | 非参数能否打败手工评分；簇是不是严重度换皮 | 同一划分上比学习器且谈校准；第二医院复现且有治疗交互 |
| G6 表型 | 簇是不是严重度换皮 | 第二医院复现，表型有治疗交互 |
| G7 观察因果 | 若按某策略治疗结局是否不同 | 写得清时间零点的靶试验 |
| G8 实施 | 预警 / LLM 是否优于常规 | **上线后病人更好**；静默部署排除在外 |

本参考讨论的「大临床数据分析方法」，主体落在 G5–G8。G1–G4 是前几卷的主场，这里只在方法依赖它们时引用。

完成标准已经立过，本参考全程适用：

- 内部区分度不再算完成
- 外集是最低配
- 静默部署被排除在外
- 不把「区分度又提高了」当作进展
- 实施研究必须同时报告持续采纳率

## 5. 六个方法家族：一张总表

按分析目标分成六个家族。六个家族回答的问题不同，因此不可互相替代，也不该互相比性能。精读篇目与机理见 [01-six-families.md](./01-six-families.md)。

| 家族 | 回答的问题 | 输出 | 入门必读 | 成熟度 | 主要风险 | 前瞻证据 |
|---|---|---|---|---|---|---|
| 一、监督预测 | 会不会发生某事 | 风险分数 | Tomašev *Nature* 2019；Hyland *Nat Med* 2020 | 高，已饱和 | 学观察过程；跨库掉点 | 有（TREWS 非随机；闭环通气随机但主终点阴性） |
| 二、横断面聚类 | 同一诊断下有几类人 | 亚型标签 | Calfee *Lancet Respir Med* 2014；SENECA *JAMA* 2019 与 2026 外验证对读 | 高 | 不可迁移；不预测治疗反应 | 有（PANTHER 招募中，见第六卷） |
| 三、轨迹聚类 | 病程有几种走法 | 轨迹类别 | Bhavani *Am J Respir Crit Care Med* 2019 | 中，增长最快 | 治疗决策伪装成轨迹 | 无 |
| 四、表征学习 | 怎么把患者变成向量 | 嵌入 | Wornow *NPJ Digit Med* 2023；ETHOS 2024 | 中 | 不可解释；受数据规模封顶 | 无 |
| 五、图方法 | 关系本身有没有信息 | 图与节点表征 | Choi GRAM，KDD 2017 | 低 | 相似度自由度过高；标签泄漏 | 无 |
| 六、因果 ML | 谁从治疗中获益 | 个体化处理效应 | Athey & Imbens *PNAS* 2016；PATH *Ann Intern Med* 2020 | 中，转向最实质 | 异质性可能是噪声 | 无，全部声明需前瞻 |

三条横向观察：

1. **「几类」这个数几乎总是四。** 静态分型是四型（SENECA αβγδ、MARS1–4），轨迹分析反复得到四类。可能是真实结构，也可能是信息准则与轮廓系数的共同偏好。至今没有人系统检验过这个数字的方法学来源。
2. **前瞻证据高度集中在两端。** 家族一有实施研究（结局多为阴性），第六卷的生物标志物分层有阳性随机试验。中间四个家族全部是回顾性的。
3. **两处天花板已经出现。** 数据量——2,800 万参数后饱和。切法——数据集、队列与预处理的影响大于模型选择。不同时公开队列定义与预处理的「我们的模型更好」，无法判断优越性来自方法还是切法。

## 6. 选题决策树

开题之前按这个顺序走。每一步「否」都是停，不是「换个网络再试」。

```
1. 问法是不是 F-00-01/02/03？
   是 → 停。伪问题。
2. 饱和度是「饱和」或「拥挤」，且你没有改问法 / 改做成标准？
   是 → 停。换模型涨 0.02 不是新问题。
3. 目标库在该域上的密度是 0 或 X？
   是 → 换库或停。不要在 MIMIC-IV 上问新生儿胎龄分层。
4. 你的输出是风险分数，还是可执行规则 / 可核对检出 / 设备设置？
   只是分数，且任务是死亡 → 几乎不会通向临床整合（见 02 第 6 节）。
5. 你是否准备公开：队列定义、时间零点、预处理、划分、校准、外集？
   否 → 写出来的「更好」无法被判断。
6. 你是否使用了测量次数、缺失指示、距上次观测？
   是 → 必须报告：去掉它们之后内 / 外验证各掉多少；否则你可能在本院习惯上拟合。
7. 你声称异质性或「优于医师」？
   是 → 必须有整体检验 / 双重 OPE + ESS；分位图和单次 WIS 不够。
8. 你打算上线？
   是 → 预先设定采纳率的分析方式。不报采纳率，阴性无法解释。
```

对本单位（围产宽表约 3,596，多组学 836，重叠 649）额外四条，来自第七卷第 37 节，不是附录，是约束：

1. 不做结构化时序的大样本表征。3,596 距标度律差三个数量级。
2. 若做人工智能，选波形或影像，不选死亡预测。先例是 HeRO。
3. 任何预警必须预先设定采纳率的分析方式。
4. 优先级低于分子分层。649 例过程与组学同源是分层资产，不是表征学习资产。
